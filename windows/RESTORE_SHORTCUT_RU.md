# Восстановление ярлыка установленного Hermes

Для компьютера Windows, где команда `hermes profile list` уже работает.
На присланном 24 сентября 2026 года снимке найден профиль `default`,
модель `qwen3.8:27b-q4_K_M` и состояние шлюза `running`.
Это подтверждает наличие установки и показывает состояние шлюза на момент снимка;
ответ Telegram-бота ещё нужно проверить в личном диалоге.

## Действия

1. Скачайте `Restore_Hermes_Shortcut.cmd` и дважды щёлкните по файлу.
2. Дождитесь зелёного сообщения `ГОТОВО: ярлык создан`.
3. На рабочем столе откройте ярлык **Hermes** двойным щелчком.
4. Для проверки существующего бота откройте его личный чат в Telegram и напишите «Привет».

Программа автоматически находит папку рабочего стола Windows, в том числе перенесённую
в OneDrive. Ярлык открывает консольный чат командой `hermes -p default chat`.
Если Hermes найден как исполняемый файл, ярлык сохраняет его полный путь.
При наличии `HERMES_HOME` программа переносит его текущее значение в команду ярлыка.
Рабочая папка — `HermesSetup` в каталоге пользователя, если она существует; иначе каталог пользователя.
Для существующего `Hermes.lnk` сначала создаётся резервная копия
в `%LOCALAPPDATA%\HermesShortcutBackup`.

После сохранения программа проверяет параметры созданного ярлыка и показывает вывод
`hermes profile list` и `hermes -p default gateway status`.
`running` означает «запущен», `stopped` — «остановлен».
Для подтверждения связи Telegram нужен ответ бота в его личном чате.

Утилита восстанавливает ярлык. Она не импортирует профиль HH, не создаёт бота,
не запускает второй шлюз и не изменяет настройки модели, токены или файлы других агентов.
Повышение прав и изменение политики выполнения PowerShell не используются.

Если команда `hermes` не найдена при двойном щелчке, запустите скачанный файл
из того окна PowerShell, где `hermes profile list` работает:

```powershell
& "$env:USERPROFILE\Downloads\Restore_Hermes_Shortcut.cmd"
```

Если файл сохранён в другой папке, используйте его фактический путь.
При ошибке сохраните снимок окна с её текстом. Наличие файла восстановления
само по себе ещё не означает, что ярлык появился на вашем компьютере.

## Проверка комплекта

Подготовлено 24 сентября 2026 г. Проверены текст команд, аргументы профиля,
сохранение резервной копии и формат CMD (UTF-8, CRLF).
Windows/COM в среде подготовки недоступны: создание `.lnk` и реальный ответ бота
должны быть подтверждены после запуска на компьютере владельца.
