# HH AI Recruiter — Hermes + Telegram

Отдельный агент для Hermes, подготовленный для Вадима Коваленко.
Вакансия HH: **137056588**. Для запуска Codex не требуется.
Проект хранится в отдельном закрытом репозитории `hh-ai-recruiter-hermes`.

## Если исчез ярлык существующего Hermes

Для уже установленного Hermes скачайте [Restore_Hermes_Shortcut.cmd](windows/Restore_Hermes_Shortcut.cmd)
и запустите двойным щелчком. Он восстановит ярлык консольного чата профиля `default`
и покажет состояние существующего шлюза. [Краткая инструкция](windows/RESTORE_SHORTCUT_RU.md).
Создание ярлыка и ответ Telegram-бота нужно подтвердить на компьютере владельца.

## Комплект

- [HH_Recruiter_Hermes_Telegram_v1.tar.gz](HH_Recruiter_Hermes_Telegram_v1.tar.gz) — импортируемый профиль Hermes.
- [HH_Recruiter_Hermes_Telegram_Start.html](HH_Recruiter_Hermes_Telegram_Start.html) — подробная инструкция; скачайте и откройте её в браузере.
- [hh-recruiter/](hh-recruiter/README.md) — исходники профиля, инструкции, локальные инструменты, примеры и тесты.
- [SHA256SUMS.txt](SHA256SUMS.txt) — контрольные суммы архива профиля и HTML-инструкции.

## Запуск

1. Импортируйте архив через Hermes Desktop или выполните из папки с архивом:

   ```sh
   hermes profile import HH_Recruiter_Hermes_Telegram_v1.tar.gz --name hh-recruiter
   ```

2. Выберите модель в Hermes. Настройте действующий токен работодателя HH и `HH_USER_AGENT` в закрытом окружении профиля.
3. Подключите личного Telegram-бота по [инструкции](hh-recruiter/references/TELEGRAM.md). Разрешите только свой числовой Telegram ID.
4. Отправьте боту [первое задание](hh-recruiter/references/START_MESSAGE.txt).

Бот предназначен для владельца. Кандидаты продолжают общение с рекрутером в HH.
Сам Hermes должен работать на включённом компьютере или сервере.

## Возможности

Чтение доступных откликов через официальный HH API, сравнение профессионального опыта,
проверка дословных свидетельств, сохранение версий оценок в SQLite, вопросы для интервью и CSV.
Шкала — 100 баллов; без необходимых свидетельств production-опыта итог ограничивается 59 баллами.
Решения о найме принимает человек. Автоматическая отправка сообщений кандидатам и изменение статусов HH не выполняются.

## Проверено

Локальные инструменты прошли 17 автоматических тестов. Проверены упаковка, демонстрационное сохранение и экспорт.
Подробности — [VALIDATION.md](hh-recruiter/VALIDATION.md).
В архиве нет действующих токенов, реальных резюме и рабочей базы. Примеры синтетические (`DEMO_ONLY`).
Реальные подключения Hermes, HH, модели и Telegram ещё нужно настроить и проверить у владельца.
