# HH-рекрутер для Hermes — запуск без Codex

Подготовлено для Вадима Коваленко. Версия 1.0, 22 сентября 2026 г.

Основной рабочий интерфейс — **личный Telegram-бот только для вас**. Вы запускаете подбор, получаете карточки и таблицы; кандидаты общаются с вами в HH. Подключение описано в references/TELEGRAM.md.

Комплект содержит готовые инструкции агента и локальные инструменты. Он подготовлен для импорта, но ещё не подключён к вашему HH и модели. Доступ к установленному у вас Hermes в этом сеансе отсутствовал.

## Что делает агент

- Читает доступные отклики по вакансии 137056588 через официальный HH API.
- Ищет в базе резюме при наличии соответствующего доступа работодателя.
- Сравнивает профессиональный опыт по прежней шкале на 100 баллов.
- Требует доказательств личного участия в AI/RAG/production; без них балл не выше 59.
- Сохраняет версии оценок в отдельную SQLite, исключает повторную запись идентичного источника.
- Исключает старый балл из текущего рейтинга, если исходное резюме изменилось, пропало или стало нечитаемым.
- Готовит вопросы и таблицу CSV, открываемую в Excel.
- Использует модель, уже выбранную в Hermes. Codex и отдельный клиент LLM не нужны.

В комплект не входит отправка сообщений кандидатам и смена статусов HH. Это помощник по разбору и подготовке решений; окончательное решение остаётся у вас.

## 1. Импортировать

1. Установите актуальный Hermes Desktop с https://hermes-agent.nousresearch.com/.
2. В Hermes Desktop нажмите кнопку импорта рядом с «+» на панели профилей и выберите HH_Recruiter_Hermes_Telegram_v1.tar.gz.
3. Импортируйте как новый профиль hh-recruiter. Если такое имя уже существует, задайте hh-recruiter-v1 — не удаляйте старый профиль.
4. Откройте импортированный профиль «HH-рекрутер Вадима». Если он пока не показан во вкладке Bots, пользуйтесь переключателем профилей: профиль уже содержит инструкции и работает в обычном чате. Добавление в список Bots не требуется для запуска.

Альтернатива — одна команда в терминале из папки с архивом:

```text
hermes profile import HH_Recruiter_Hermes_Telegram_v1.tar.gz --name hh-recruiter
```

Это команда готового Hermes, писать программу или запускать Codex не требуется.

Если старая версия Hermes не умеет импортировать профили, обновите её. Ручной вариант: создать Bots → New Agent, скопировать SOUL.md в Custom SOUL.md, а scripts/ и references/ перенести в корень нового профиля. Одного промпта без папки scripts недостаточно для готового подключения к HH и локальной проверки баллов.

## 2. Подключить модель

В импортированном профиле выберите провайдера и модель через настройки Hermes. При терминальном запуске:

```text
hermes -p hh-recruiter model
hermes -p hh-recruiter chat
```

Для независимости от Codex выберите, например, Nous Portal, OpenRouter или доступную локальную модель. Приложение Hermes само отправляет ей запросы. Профиль не копирует ключи из других профилей. В актуальном руководстве Hermes указано требование контекста не менее 64K; у локальной модели надо настроить и проверить этот размер, а не полагаться только на её название. Доступность памяти и качество работы зависят от компьютера и модели.

Hermes — открытое ПО. Модель, сервер и услуги HH могут оплачиваться отдельно. Полностью бесплатная работа не гарантируется; новая платная услуга этим комплектом не подключается.

## 3. Подключить HH

Нужен действующий токен работодателя из зарегистрированного приложения HH и права на нужные методы. Прежний отчёт показывает, что ранее HH API уже использовался, но актуальный срок токена и доступность услуги сейчас не проверены.

Задайте две переменные в закрытых настройках окружения импортированного профиля:

| Переменная | Значение |
|---|---|
| HH_ACCESS_TOKEN | Действующий OAuth access token работодателя |
| HH_USER_AGENT | Название приложения и ваш реальный контактный email |

Ручной способ — открыть .env в папке импортированного профиля локальным редактором, добавить эти значения и перезапустить профиль Hermes. Не вводите токен обычным сообщением в чат. Не вставляйте секрет в команду терминала, которая попадёт в историю. Пример HH_USER_AGENT: HH-Hermes-Recruiter/1.0 (ваш реальный контактный адрес); текст примера нужно заменить значением владельца приложения.

Папка профиля обычно находится в ~/.hermes/profiles/hh-recruiter/; на Windows — в .hermes/profiles/hh-recruiter внутри домашней папки пользователя, если при установке Hermes не указан иной путь. Пользуйтесь фактическим расположением профиля из настроек.

Если токена пока нет, используйте существующий OAuth-процесс вашего приложения работодателя или кабинет https://dev.hh.ru/. Новый OAuth callback-сервис и автоматическое обновление токенов в этот комплект не входят. При истечении токена чтение остановится с понятной ошибкой 401. Для непрерывной серверной работы обновление доступа потребуется настроить отдельно.

403 означает недостаточные права/услугу, а не ошибку кандидата. Поиск по базе и работа с уже полученными откликами имеют разные условия доступа. Коннектор их не обходит. При чтении резюме связанный отклик может стать просмотренным на стороне HH.

## 4. Подключить личного Telegram-бота

В нужном профиле откройте Messaging → Telegram → Create with QR, завершите подтверждение на iPhone и проверьте, что разрешён только ваш числовой Telegram ID. Откройте личный чат с созданным ботом. Подробный ручной вариант через @BotFather и gateway setup — в references/TELEGRAM.md.

Реальный токен бота не создан и к этому архиву не привязан: подключение выполняется в вашей установке Hermes. Кандидатов подключать к боту не нужно.

## 5. Первое задание

Скопируйте в личный Telegram-чат с вашим ботом:

> Начни работу HH-рекрутера по вакансии 137056588. Проверь доступ работодателя, прочитай актуальные требования и выполни один проход по откликам. Оцени новые резюме по нашей шкале, длинные прочитай полностью. Покажи ошибки, приоритетных кандидатов с цитатами и сохрани таблицу CSV. Вопросы подготовь как черновики. Если HH не подключён, объясни, каких настроек не хватает, и продолжи с предоставленными файлами.

Тот же текст сохранён в references/START_MESSAGE.txt. Если хотите начать без HH, приложите полные тексты 2–3 резюме и напишите: «Сравни этих кандидатов для вакансии специалиста по ИИ-агентам; сохрани оценки и вопросы». Распознавание сканов и PDF/DOCX зависит от возможностей вашей установки Hermes; гарантированный вход для локальной проверки — UTF-8 JSON с полным профессиональным текстом.

## Переход от прежнего рекрутера

В отчёте от 18.09.2026 указаны 196 обработанных откликов, 183 оценки, 13 резюме без оценки из-за лимита текста. Эти сведения включены только как история проекта. Реальные карточки, переписка и старая база в архив не копировались.

Перед переносом попросите Hermes сверить текущую выгрузку прежней системы с HH. Старые баллы относятся к другой реализации: не смешивайте их с новой версией без явной маркировки. Для тех 13 резюме нужна полная повторная обработка, без обрезки текста. Новый профиль не выключает старый мониторинг. Сначала проверьте и согласуйте перенос, затем задавайте новое расписание; в комплекте нет активных заданий по времени.

Для работы с iPhone используйте этот личный Telegram-бот. Сам Hermes должен работать на включённом компьютере/сервере. Реальное Telegram-подключение и рассылки этим комплектом не создавались.

Инструменты не требуют установки сторонних Python-пакетов. При ошибке поиска python используйте интерпретатор из вашей установки Hermes; на macOS/Linux обычно python3. # Личный Telegram-бот для управления подбором

Выбранный пользователем режим: **только для Вадима**. Бот — рабочий чат владельца. Кандидаты продолжают общение в HH; их не подключают к этому боту.

## Подключение без программирования

1. Импортируйте профиль hh-recruiter в Hermes Desktop и подключите модель.
2. Переключитесь именно на этот профиль.
3. Откройте Messaging → Telegram → Create with QR. Отсканируйте QR или откройте ссылку на iPhone. Следуйте подтверждениям Telegram.
4. Мастер Hermes создаёт бота, определяет ваш Telegram ID и записывает токен и разрешённого пользователя в текущий профиль. Проверьте, что разрешён только ваш ID.
5. Откройте личный диалог с ботом и отправьте: «Статус подключения». Затем: «Начать подбор по вакансии 137056588».

Этот путь описан в актуальной официальной документации Hermes. Названия элементов в старой сборке могут отличаться. Профиль и шлюз должны принадлежать одному hh-recruiter, иначе Telegram будет обращаться к другому агенту.

## Если QR-кнопки нет

1. В официальном @BotFather отправьте /newbot.
2. Укажите название «HH-рекрутер Вадима» и свободное имя, оканчивающееся на bot. Имя можно выбрать по наличию; конкретный username заранее не создан и не занят этим комплектом.
3. Сохраните выданный токен в защищённых настройках Telegram нужного профиля Hermes.
4. Укажите свой числовой Telegram ID в TELEGRAM_ALLOWED_USERS. Не используйте имя @username вместо числа. ID можно получить через показанный в документации Hermes способ или мастер подключения.
5. Запустите gateway этого профиля. Через терминал используются штатные команды:

```text
hermes -p hh-recruiter gateway setup
hermes -p hh-recruiter gateway
```

Во время setup выбирается Telegram, вводится токен и ID. Секреты вводятся в мастере, а не в чат с ИИ. Если профиль импортирован под другим именем, используйте именно его. Для непрерывной работы gateway нужно оформить как службу вашей системы средствами Hermes после проверки. Комплект не устанавливает службу сам.

Пример иллюстративный, реального кандидата с этим баллом комплект не выбирал.

## Что должно работать постоянно

- Компьютер/сервер с Hermes и gateway этого профиля.
- Интернет, действующий доступ модели и HH.
- Действительный Telegram-токен и разрешённый ID владельца.

Когда компьютер выключен, бот не выполняет подбор. Пока подключение не проверено реальным сообщением, нельзя считать бота запущенным. Действующий токен HH может потребовать обновления; коннектор не обновляет его автоматически.

## Telegram — основной интерфейс владельца

## Запуск и расположение инструментов

У этого профиля есть scripts/hh_api.py, scripts/review.py, references/ и workspace/. Для абсолютных путей найди корень текущего профиля из контекста Hermes или переменной HERMES_HOME. Ниже команды с относительными путями; выполнять из корня ЭТОГО профиля. Это внутренние действия агента — пользователю достаточно написать задачу обычным текстом.

Проверка работодателя:
`python scripts/hh_api.py check`

Один проход по всем доступным коллекциям откликов:
`python scripts/hh_api.py sync --vacancy 137056588`

Поиск, одна страница, без фильтров по личным характеристикам:
`python scripts/hh_api.py search --query "RAG AI agents Python" --page 0 --out workspace/search/page0.json`
Это пример стартового запроса, а не гарантированно оптимальный запрос для HH. Уточняй формулировки по реальной вакансии и результатам. Если нужен следующий лист, используй фактические pages из ответа. Не объявляй поиск полным, пока не учтены все запрошенные страницы. Смена запроса — отдельная выборка; сохраняй запрос и номер страницы в отчёте.

Чтение конкретного полного резюме:
`python scripts/hh_api.py resume --id RESUME_ID --vacancy 137056588`
Вместо RESUME_ID используй только реально возвращённый HH идентификатор. Карточки поиска содержат лишь ID и должность: по ним нельзя выставлять окончательную оценку.

Валидация и сохранение оценки:
`python scripts/review.py save --profile workspace/inbox/137056588/RESUME_ID.json --assessment workspace/assessments/RESUME_ID.json`

Рейтинг и CSV, открываемый в Excel:
`python scripts/review.py rank --vacancy 137056588 --csv workspace/reports/candidates.csv`

Флаг --db, если он нужен, идёт ДО подкоманды save/rank. По умолчанию база находится внутри этого профиля в workspace/recruiter.sqlite3. Не подставляй старую базу прежнего приложения: у них разные схемы. Инструменты не вызывают стороннюю модель: рассуждение и подготовка assessment происходят в Hermes.

## Подключение HH

HH_ACCESS_TOKEN и HH_USER_AGENT должны быть заданы в защищённых настройках окружения профиля. HH_USER_AGENT — название приложения и реальный контактный адрес владельца приложения. Не выдумывай контакт. Токен не выводи в чат, логи, команды и отчёты. Не читай файл .env целиком инструментом просмотра, не выводи переменные окружения. Если доступ не настроен, скажи «Для чтения HH нужен действующий доступ работодателя» и продолжи доступную работу с файлами.

Готовый коннектор выполняет только GET к https://api.hh.ru и блокирует перенаправления. При 401 нужен действующий токен; при 403 проверь права и доступность услуги; при 404 документ недоступен; при 429 уважай лимит. Не обходи запрет доступа и не переходи к сбору закрытых резюме через браузер. HH может отметить отклик просмотренным при чтении связанного резюме; это возможный эффект чтения на стороне HH.

Автоматическое обновление токенов в этот комплект не входит. Используй действующий доступ, полученный через зарегистрированное приложение работодателя. Покупку услуг и регистрацию нового приложения не выполняй без запроса пользователя. Успешный /me подтверждает тип пользователя, но не доступность всех платных методов.

## Рабочий процесс

1. Определи вакансию и источник. Сначала проверь актуальные требования. Если доступен лишь прежний текст, явно пометь его датой.
2. Выполни один sync или прочитай предоставленные файлы. После sync прочитай _sync_status.json и _vacancy.json. complete=false означает частичный результат; не скрывай ошибки.
3. Не считай совпадение ФИО дублем. Основной ключ — vacancy_id + resume_id. При изменении профессионального текста создаётся новая версия оценки. Перед новым анализом проверь текущую сохранённую запись и SHA исходника. Совпадение SHA и версии рубрики позволяет использовать кэш, с указанием даты. В результате rank только eligible_for_ranking=true допускается к текущему рейтингу. При changed/missing/unreadable_or_incomplete/not_checked старый балл хранится как исторический, а актуальный score_total=null; не подставляй исторический балл обратно в топ. Не запускай несколько sync одного профиля одновременно.
4. Читай professional_text полностью. Для длинного документа используй последовательные части с номерами строк. Веди контроль прочитанных диапазонов; пропущенный диапазон означает, что анализ не завершён. Не обрезай до первых 16 000 символов, не ограничивайся первым местом работы. Цитаты сохраняй дословно вместе с контекстом проекта. При нехватке контекста сначала вынеси доказательства по каждому проекту в локальные заметки, затем собери общую оценку.
5. Оцени каждый критерий по таблице ниже. Отдельно проверь пять измерений production на одном связном проекте. Наличие названия инструмента не подтверждает практику.
6. Создай assessment JSON по references/assessment_example.json. Результат модели не является готовым баллом до запуска review.py. Если проверка цитат обнулила балл, проверь первоисточник; не сочиняй цитату для прохождения проверки.
7. Сохрани результат валидатором. Обновлённые ответы кандидата добавляй в новый полный профессиональный источник с пометкой происхождения и даты; сохрани предыдущую версию. Не редактируй SQLite напрямую.
