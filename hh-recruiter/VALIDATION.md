# Проверка комплекта

Дата: 22.09.2026. Python 3.12.14.

- 17 автоматических проверок: шкала и предел 59, тип boolean, отсутствие/выдуманные цитаты, связь production по одному проекту, неполный исходник, разные ID с одинаковым текстом, версии источника, повторы, формулы CSV, ограничения хоста HH, полная пагинация, сохранение длинного текста, изоляция ошибок отдельных резюме.
- Проведена независимая проверка кода. Исправлены две найденные ошибки: возврат неправильной версии из кэша и попадание устаревшей оценки в текущий рейтинг. Четыре регрессионных CLI-теста сначала воспроизвели дефекты, затем прошли после исправления.
- Старый балл исключается из текущего рейтинга при изменённом, отсутствующем или нечитаемом источнике. При возврате исходника к ранее оценённой версии используется соответствующая сохранённая оценка.
- Проверка синтетического примера включает сохранение, повторное сохранение без новой записи и CSV-экспорт из отдельной демонстрационной базы.
- Исходники Python проверены на синтаксис. YAML и JSON проверены на читаемость.
- Архив содержит один корневой каталог hh-recruiter, не содержит токенов, настоящих резюме, SQLite, кэшей и журналов. Структура сверена с официальным import_profile Hermes.

Не проверено вживую: подключение к аккаунту HH, права платных методов, OAuth/срок токена, фактический импорт в установленный Hermes, ответы выбранной модели, создание/авторизация Telegram-бота и доставка файлов в Telegram. Для этого нужен компьютер/сервер пользователя, подключённая модель и его доступы. Кандидатам сообщения не отправлялись; реальные отклики в этом сеансе не загружались.

Смысл и достоверность утверждений кандидата не устанавливаются валидатором цитат. Инструкции требуют проверки смысловой связи в Hermes и уточнений на интервью. Разбор свободного текста не гарантирует удаления любых личных данных.

Повторить локальные тесты из корня профиля:

```text
python -m unittest discover -s tests -v
python -m compileall -q scripts
```

Использованные навыки проверки: test-driven-development, requesting-code-review, receiving-code-review, systematic-debugging, verification-before-completion. Программная часть не зависит от этих навыков и не требует их установки в Hermes.
