# HH-рекрутер для Hermes — запуск без Codex

Подготовлено для Вадима Коваленко. Версия 1.0, 22 сентября 2026 г.

Основной рабочий интерфейс — **личный Telegram-бот только для вас**. Вы запускаете подбор, получаете карточки и таблицы; кандидаты общаются с вами в HH. Подключение описано в references/TELEGRAM.md.

Комплект содержит готовые инструкции агента и локальные инструменты. Он подготовлен для импорта, но ещё не подключён к вашему HH и модели. Доступ к установленному у вас Hermes в этом сеансе отсутствовал.

## Что делает агент

- Читает доступные отклики по вакансии 137056588 через официальный HH API.
- Ищет в базе резюме при наличии соответствующего доступа работодателя.
- Сравнивает профессиональный опыт по прежней шкале на 100 баллов.
- Требует доказательств личного участия в AI/RAG/production; без них балл не выше 59.
- Сохраняет версии оценок в отдельную SQLite, исключает повторную запись идентичного источника.
- Исключает старый балл из текущего рейтинга, если исходное резюме изменилось, пропало или стало нечитаемым.
- Готовит вопросы и таблицу CSV, открываемую в Excel.
- Использует модель, уже выбранную в Hermes. Codex и отдельный клиент LLM не нужны.

В комплект не входит отправка сообщений кандидатам и смена статусов HH. Это помощник по разбору и подготовке решений; окончательное решение остаётся у вас.

## 1. Импортировать

1. Установите актуальный Hermes Desktop с https://hermes-agent.nousresearch.com/.
2. В Hermes Desktop нажмите кнопку импорта рядом с «+» на панели профилей и выберите HH_Recruiter_Hermes_Telegram_v1.tar.gz.
3. Импортируйте как новый профиль hh-recruiter. Если такое имя уже существует, задайте hh-recruiter-v1 — не удаляйте старый профиль.
4. Откройте импортированный профиль «HH-рекрутер Вадима». Если он пока не показан во вкладке Bots, пользуйтесь переключателем профилей: профиль уже содержит инструкции и работает в обычном чате. Добавление в список Bots не требуется для запуска.

Альтернатива — одна команда в терминале из папки с архивом:

```text
hermes profile import HH_Recruiter_Hermes_Telegram_v1.tar.gz --name hh-recruiter
```

Это команда готового Hermes, писать программу или запускать Codex не требуется.

Если старая версия Hermes не умеет импортировать профили, обновите её. Ручной вариант: создать Bots → New Agent, скопировать SOUL.md в Custom SOUL.md, а scripts/ и references/ перенести в корень нового профиля. Одного промпта без папки scripts недостаточно для готового подключения к HH и локальной проверки баллов.

## 2. Подключить модель

В импортированном профиле выберите провайдера и модель через настройки Hermes. При терминальном запуске:

```text
hermes -p hh-recruiter model
hermes -p hh-recruiter chat
```

Для независимости от Codex выберите, например, Nous Portal, OpenRouter или доступную локальную модель. Приложение Hermes само отправляет ей запросы. Профиль не копирует ключи из других профилей. В актуальном руководстве Hermes указано требование контекста не менее 64K; у локальной модели надо настроить и проверить этот размер, а не полагаться только на её название. Доступность памяти и качество работы зависят от компьютера и модели.

Hermes — открытое ПО. Модель, сервер и услуги HH могут оплачиваться отдельно. Полностью бесплатная работа не гарантируется; новая платная услуга этим комплектом не подключается.

## 3. Подключить HH

Нужен действующий токен работодателя из зарегистрированного приложения HH и права на нужные методы. Прежний отчёт показывает, что ранее HH API уже использовался, но актуальный срок токена и доступность услуги сейчас не проверены.

Задайте две переменные в закрытых настройках окружения импортированного профиля:

| Переменная | Значение |
|---|---|
| HH_ACCESS_TOKEN | Действующий OAuth access token работодателя |
| HH_USER_AGENT | Название приложения и ваш реальный контактный email |

Ручной способ — открыть .env в папке импортированного профиля локальным редактором, добавить эти значения и перезапустить профиль Hermes. Не вводите токен обычным сообщением в чат. Не вставляйте секрет в команду терминала, которая попадёт в историю. Пример HH_USER_AGENT: HH-Hermes-Recruiter/1.0 (ваш реальный контактный адрес); текст примера нужно заменить значением владельца приложения.

Папка профиля обычно находится в ~/.hermes/profiles/hh-recruiter/; на Windows — в .hermes/profiles/hh-recruiter внутри домашней папки пользователя, если при установке Hermes не указан иной путь. Пользуйтесь фактическим расположением профиля из настроек.

Если токена пока нет, используйте существующий OAuth-процесс вашего приложения работодателя или кабинет https://dev.hh.ru/. Новый OAuth callback-сервис и автоматическое обновление токенов в этот комплект не входят. При истечении токена чтение остановится с понятной ошибкой 401. Для непрерывной серверной работы обновление доступа потребуется настроить отдельно.

403 означает недостаточные права/услугу, а не ошибку кандидата. Поиск по базе и работа с уже полученными откликами имеют разные условия доступа. Коннектор их не обходит. При чтении резюме связанный отклик может стать просмотренным на стороне HH.

## 4. Подключить личного Telegram-бота

В нужном профиле откройте Messaging → Telegram → Create with QR, завершите подтверждение на iPhone и проверьте, что разрешён только ваш числовой Telegram ID. Откройте личный чат с созданным ботом. Подробный ручной вариант через @BotFather и gateway setup — в references/TELEGRAM.md.

Реальный токен бота не создан и к этому архиву не привязан: подключение выполняется в вашей установке Hermes. Кандидатов подключать к боту не нужно.

## 5. Первое задание

Скопируйте в личный Telegram-чат с вашим ботом:

> Начни работу HH-рекрутера по вакансии 137056588. Проверь доступ работодателя, прочитай актуальные требования и выполни один проход по откликам. Оцени новые резюме по нашей шкале, длинные прочитай полностью. Покажи ошибки, приоритетных кандидатов с цитатами и сохрани таблицу CSV. Вопросы подготовь как черновики. Если HH не подключён, объясни, каких настроек не хватает, и продолжи с предоставленными файлами.

Тот же текст сохранён в references/START_MESSAGE.txt. Если хотите начать без HH, приложите полные тексты 2–3 резюме и напишите: «Сравни этих кандидатов для вакансии специалиста по ИИ-агентам; сохрани оценки и вопросы». Распознавание сканов и PDF/DOCX зависит от возможностей вашей установки Hermes; гарантированный вход для локальной проверки — UTF-8 JSON с полным профессиональным текстом.

## Шкала

| Критерий | Баллы |
|---|---:|
| AI-агенты | 25 |
| RAG | 20 |
| Реальные внедрения и личная роль | 20 |
| Python/backend/API/интеграции | 15 |
| Docker/Linux/развёртывание | 10 |
| Git/CI/CD | 5 |
| Самостоятельность и бизнес-результат | 5 |

Без пяти свидетельств об одном рабочем проекте — не более 59/100. Порог приоритетного интервью — 80 при подтверждении по тексту. Дословная цитата подтверждает наличие утверждения в источнике, но не правдивость утверждения: это уточняется на интервью. Простой перечень технологий не подтверждает опыт. Возраст, пол, фото и другие личные/чувствительные признаки не являются критериями.

## Переход от прежнего рекрутера

В отчёте от 18.09.2026 указаны 196 обработанных откликов, 183 оценки, 13 резюме без оценки из-за лимита текста. Эти сведения включены только как история проекта. Реальные карточки, переписка и старая база в архив не копировались.

Перед переносом попросите Hermes сверить текущую выгрузку прежней системы с HH. Старые баллы относятся к другой реализации: не смешивайте их с новой версией без явной маркировки. Для тех 13 резюме нужна полная повторная обработка, без обрезки текста. Новый профиль не выключает старый мониторинг. Сначала проверьте и согласуйте перенос, затем задавайте новое расписание; в комплекте нет активных заданий по времени.

Для работы с iPhone используйте этот личный Telegram-бот. Сам Hermes должен работать на включённом компьютере/сервере. Реальное Telegram-подключение и рассылки этим комплектом не создавались.

## Проверка локальных инструментов

Из корня профиля, используя Python Hermes:

```text
python scripts/review.py --db workspace/demo.sqlite3 save --profile references/demo_profile.json --assessment references/demo_assessment.json
python scripts/review.py --db workspace/demo.sqlite3 rank --vacancy 137056588 --csv workspace/reports/demo.csv
```

Это синтетический кандидат DEMO_ONLY, ожидается 100 баллов по заданным демонстрационным свидетельствам. Он сохраняется в отдельную demo.sqlite3 и не должен попадать в рабочий рейтинг. Пример проверяет технику сохранения и арифметики, не качество оценки реального человека.

Инструменты не требуют установки сторонних Python-пакетов. При ошибке поиска python используйте интерпретатор из вашей установки Hermes; на macOS/Linux обычно python3. Ниже технические ограничения, которые следует учитывать: свободный текст может содержать личные данные; проверка цитат не доказывает смысл или честность резюме; режим параллельных sync одного профиля не предусмотрен; срок токена не обновляется автоматически.

Подробные источники и версия рубрики — references/SOURCES.md. Результат проверки этого комплекта — VALIDATION.md.
