2. Добавить изолированную очередь SQLite и отдельный Telegram consumer с проверкой владельца. Выполнено в коде.
3. Использовать актуальный HH Chat API и UUID идемпотентности. Выполнено в коде; нужны реальные права HH.
4. Добавить unit-тесты до реализации, проверить прежние тесты, CLI и синтаксис. Выполнено: 39 тестов.
5. Сохранить отдельную ветку и PR с инструкцией запуска.
6. Сквозной запуск на Windows: заблокирован отсутствием подключённого терминала, отдельного токена бота и локального доступа HH в текущей среде.
